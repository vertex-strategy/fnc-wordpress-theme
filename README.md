# Forum Numérique Congo — template WordPress

Thème **« Forum Numérique Congo »** + extensions **« FNC Content Model »** et **« FNC Core »** :
le site institutionnel bilingue (français / anglais) du Forum — éditions, intervenants, programme,
ressources, partenaires, actualités et demandes en ligne.

La documentation est répartie par usage :

| Document | Public | Contenu |
|---|---|---|
| [`INSTALL.md`](INSTALL.md) | Intégrateur | Installation du paquet, prérequis, mise à jour, durcissement serveur. |
| [`GUIDE.md`](GUIDE.md) | Éditeur / administrateur | Administration et édition du contenu, sans écrire de code. |
| [`DEVELOPER.md`](DEVELOPER.md) | Développeur | Architecture, modèle de réglages, API, hooks, build — **manuel complet**. |

> **Développeurs : commencez par [`DEVELOPER.md`](DEVELOPER.md)** (prise en main, architecture et
> « faire une correction de bout en bout »).
